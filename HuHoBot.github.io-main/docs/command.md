# HuHoBotPenguin 命令列表

> 权限列 `管理员` 受群配置的「管理方式」影响（`/管理方式`）：默认仅数据库管理员；可切换为 QQ 群主/管理员判定或双重要求。
>
> 参数约定：`(必选)` `[可选]`
>
> 如输入的名称带有空格，请使用英文双引号 `"` 包裹

---

!!! note

    新版已取消`/执行`命令，可使用 `/关键词 参数1 参数2` 直接执行

    如果执行者拥有管理员权限，则自动使用原先的`/管理员执行`

## 帮助

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/帮助` | — | 列出所有内置命令和自定义命令 | 所有人 |
| `/版本` | — | 查看版本信息 | 所有人 |

## QQ 绑定

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/绑定` | `(游戏ID)` | 绑定 QQ 账号到 Minecraft 玩家（自动同步白名单） | 所有人 |
| `/解除绑定` | — | 解除当前绑定（自动移除白名单） | 所有人 |
| `/MC显示名称` | `(MC/QQ)` | 切换 QQ→游戏 方向的发送者名称显示 | 所有人 |
| `/QQ显示名称` | `(MC/QQ)` | 切换游戏→QQ 方向的发送者名称显示 | 所有人 |

!!! note

    绑定后发送 `/发信息` 到游戏时，发送者名称会根据绑定设置显示为游戏ID或QQ昵称。

## 服务器管理

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/绑定` | `(serverId) [多群]` | 发起群与服务器的绑定；无参查看当前绑定 | 绑定：管理员；查看：所有人 |
| `/解绑` | `[serverId]` | 无参弹出选择框；有参直接解除指定服务器绑定 | 管理员 |
| `/设置服务器` | `[serverId]` | 无参弹出服务器选择框；有参直接打开指定服务器操作面板 | 管理员 |
| `/命名服务器` | `(serverId) (名称)` | 重命名已绑定的服务器 | 管理员 |

## 命令执行

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/执行` | `(关键词) [参数...]` | 以普通身份执行服务端自定义命令（管理员自动使用管理员权限） | 所有人 |

|---|---|---|---|

## AI Agent

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/agent` | `(任务描述)` | 启动 AI Agent 执行服务器管理任务 | 管理员 |
| `/newsession` | — | 清除 AI 会话上下文，下次 /agent 开始全新对话 | 管理员 |
| `/stop` | — | 紧急停止所有 AI 任务 | 管理员 |

!!! note

    AI Agent 支持两种执行模式：`auto`（AI 直接执行命令）和 `manual`（管理员通过 QQ 按钮审批）。
    详细文档请查看 [AI Agent](Agent/index.md)。

## 游戏内命令

以下命令在 Minecraft 游戏内使用：

| 命令 | 参数 | 说明 | 权限 |
|---|---|---|---|
| `/qqbind` | `(验证码)` | 完成 QQ 绑定的游戏内验证（需先在 QQ 端发起 /绑定） | 所有人 |

## 自定义命令

自定义命令在配置文件中定义，支持以下占位符：

| 占位符 | 说明 |
|---|---|
| `{params}` | 完整参数 |
| `{group}` | 群 ID |
| `{user}` | 用户 ID |
| `{name}` | 绑定的 MC 玩家名（未绑定则返回 QQ 用户名） |
| `{nickname}` | 用户的 QQ 昵称 |
| `{0}`、`{1}` | 按空格拆分后的参数 |
| `&1`、`&2` | 按空格拆分后的参数（另一种语法） |
